# S. Vijayaragavan — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP file.
2. Open the `vijayaragavan_portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension in VS Code.
4. Right-click `index.html` and choose **Open with Live Server**.

## Publish with GitHub Pages
1. Create/open a GitHub repository.
2. Upload the contents of this folder to the repository root (the `index.html` file must be at the root).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. After GitHub Pages finishes publishing, the site URL is usually `https://YOUR-USERNAME.github.io/` for a repository named `YOUR-USERNAME.github.io`, or `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` for another repository name.

## Before publishing
- Check that your phone number and email are correct and that you are comfortable displaying them publicly.
- Replace the GitHub link with your actual profile URL.
- The Inventory & Sales Dashboard is clearly labelled as a portfolio demonstration concept, not a completed project.
- The Civil Supplies System details are based on the project description in the supplied resume.
- The Reference section from the resume has intentionally not been included.

## Important
This is a static front-end portfolio. Python/Django and React are listed as skills; no Django backend or React app is connected in this version.
